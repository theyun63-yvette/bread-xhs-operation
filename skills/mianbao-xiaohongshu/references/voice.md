# 文风与协作编辑

依据：用户的原始九图配文、其明确要求「文字的信息多一点，保留我的个人特色和文风」，以及最终采纳的修订。以下是偏好与方法，不是固定文案公式。

## 识别面包的声音

- 真实行程和日期、很具体的小事，与直接的情绪反应交织。
- 有抒情和思考，也有自嘲、兴奋、口语。「哈哈哈哈」「hh」「！！」「于是怒买之」等可以自然存在。
- 对朋友说话的感觉，允许中英混用、朋友代称和emoji。修改字数或格式前，先看它们是否提供个人辨识度。
- 成长感来自经历，也允许最后有用户自己的感受。不能机械删除所有抽象表达或强行添加普适道理。

## 用户原话样本

这些语句来自用户消息或上传图片中的原文；用于识别表达习惯，不要机械重复到所有作品。

| 原话/短片段 | 有效之处 |
| --- | --- |
| 笑死我了 我来深圳两周了，但是收到了在天津的更好的offer | 直接反应带着真实转折；对外是否使用还要服从本篇边界 |
| 这一天冰冷的工时终于变成了温暖的日本游… | 把挣钱和体验连在一起，有个人语言 |
| 两个人专门找了妆造团队打算狠狠出片 | 有准备细节和期待，之后的大雨才有意思 |
| 有好多喜欢的品牌店药妆店 简直是大逛特逛！！ | 透露兴趣和逛街时的状态，不是必须删除的旁枝 |
| 完全无缝衔接的一位！！💪 | 时间线之后自然的自我调侃 |
| 不错！很有精神！！ | 认真准备上班，同时会夸自己，短但有性格 |
| 正好赶上了万圣节限定于是怒买之 | 很具体的消费情境，加上自己的说法 |
| 培养生活的支点、提高对世界爱的能力 | 用户自己的阶段感受，适合具体经历后的收尾 |

## 默认编辑尺度

先保留事实和表达，再动可读性：修病句、语序、日期标点、分段，合并真正重复的意思。需要更大幅度重写时说明哪些内容被改变以及理由。

示例：

原句：周五lastday周六退房周日来到深圳开始过夏天，周一入职了新公司，完全无缝衔接的一位！！

合适的轻编辑：
周五 last day，周六退房
周日来到深圳开始过夏天，周一入职新公司
完全无缝衔接的一位！！

容易丢失个人性的改法：勇敢走出舒适圈，在新的城市遇见更好的自己。

原句：感觉穿搭的很职场，不错！很有精神！！

合适的轻编辑：感觉今天穿得很职场。不错！很有精神！！

这里不需要额外补一句泛泛的「记录新城市里的自己」。

## 图文审稿

- 用户还在发图时不要提前判定整套结构；收到后按用户编号或场景标识逐张看。
- 分开检查：照片作用、正文信息、个人语气、视觉可读性。看不清文字要说明，不能猜读。
- 对照片选取看具体内容：场景、人的反应、生活细节与前后关系。未看到图片时只能给选图标准，不装作已经选过。
- 图文允许较多字。把事件与感受分段；长段落可以左对齐；文字较多先调整位置、底色和对比，不用一味缩小字号或删故事。
- 原图已好用就保留，不追求九张同一种光线和颜色，也不以滤镜替代个人内容。
- 用户请求实际编辑图片时才进入编辑工具流程；评审建议不等于已经改过图。

整套稿件常用表格：图片/可直接用的完整文案/具体调整理由。需要解释关注作用时讲可能的阅读机制，不许编造涨粉提升比例。

## 标题、正文与话题

- 评估标题、封面和开头的配合，既支持简短聊天式标题，也支持阶段系列名。
- 阶段综述封面可以提及未逐图展示的近况；集中写某个事件的文章可以收窄标题。两种选择按本篇意图讨论。
- 正文适合补背景、对老读者说话、连接后续；不必逐字重述所有图中文字。想保留重复作为呼应时尊重用户选择。
- 标签按真实题材和身份选，避免不相干活动。数量没有被设成硬性规则；不把话题当作推荐保证，当前活动或平台限制需要核实时再查。

## 选题与复盘

- 从已有经历和愿意表达的素材出发，一个推荐先讲清角度，再决定要不要多个备选。
- 「发生了什么＋具体细节＋自己的反应」是可用提示，不是每张强制公式。
- 合集与单篇能承接：前者交代近况，后者增加过程、细节或不同视角。少量复用照片可以，避免把同一段文字原样拉长。
- 数据可得时区分点击/读完/主页访问/新增关注/收藏/评论；哪个指标缺失就说未知。结合内容主题、发布条件和创作成本，不因一篇波动断言账号转型成功或失败。
- 用户需要深度博主分析时，可以讲得细；正在闲聊下一篇时先回应眼下问题，不反复做定位汇报。
