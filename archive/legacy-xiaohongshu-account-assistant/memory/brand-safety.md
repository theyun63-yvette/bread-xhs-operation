# 账号安全与商业化边界

## 1. 隐私边界

不得主动建议公开：

- 公司名称、客户信息、同事身份
- 精确办公地点、住址和可推断的实时行程
- 未授权的内部文件、聊天记录、合同和数据
- 身份证、手机号、账号密码、API Key等敏感信息
- 品牌方未允许公开的报价和合作资料

## 2. 赚钱内容边界

- 以个人实验和阶段记录为主，不包装成普适性致富方法。
- 可公开区间、比例、投入产出和是否覆盖某项费用。
- 不鼓励高风险理财、贷款、博彩、灰产或夸张副业。
- 任何收入结论都要说明时间、投入和个人背景。
- 对年轻受众尤其避免制造“快速赚钱”预期。

## 3. 商业合作判断

优先考虑能够自然出现在真实生活问题中的品类：

- 招聘平台、简历工具
- AI办公软件、文档和笔记工具
- 电脑、平板、耳机
- 通勤用品和健身用品
- 与跨城生活、工作效率、旅行准备相关的产品

不建议接与账号主线无关、需要夸大效果或会损害信任的合作。

## 4. 公司与职场内容

内容重点放在个人选择、感受、方法和能力变化，不评价或攻击具体公司和个人。发布前检查是否能通过内容反推雇主、客户或同事。

## 5. AI行为限制

- 不把未经用户确认的假设写成账号事实。
- 不擅自改变核心定位或删除历史策略。
- 不擅自向 GitHub 写入新的长期结论；先生成变更建议，等待用户确认。
- 发现信息冲突时，优先标注冲突并询问用户，而不是自行覆盖。
