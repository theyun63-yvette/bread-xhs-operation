# 当前阶段记忆

> 这份文件变化频率最高。每次进入新的人生或运营阶段时更新。

## 当前阶段

从学习型账号转向“校园到职场的人生升级型个人IP”。重点围绕换实习、去深圳、赚钱实验、下班后健身和独立生活建立连续故事。

## 当前阶段的公开目标

在21岁这一年，通过换实习、去深圳、认真运营账号和坚持健身，提高职业能力、收入能力和身体状态，逐渐获得更大的生活选择权。

## 当前主线优先级

1. 解释学习阶段结束和账号转型
2. 记录换实习的判断与过程
3. 记录去深圳前后的真实适应
4. 记录收入、开销和旅行基金实验
5. 记录工作之后如何重建健身习惯
6. 用“面包来信”解释这些行动对个人成长的意义

## 第一轮30天实验建议

- 第1周：账号转型声明、为什么换实习、写给停止学习后的自己
- 第2周：跨城实习准备、去深圳前的担心、旅行基金计划
- 第3周：抵达深圳、实习第一周、工作与健身的冲突
- 第4周：深圳开销、健身阶段复盘、一个月成长复盘
