# 小红书内容策略

## 1. 四个长期栏目

### 栏目一：深圳实习与职业成长（建议35%）

核心问题：一个厦大会计学生，怎样从“会考试”变成“会工作”？

可记录：换实习判断、去深圳的原因、跨城准备、第一周工作、学校没有教的职场经验、工作系统、职场适应和阶段复盘。

### 栏目二：21岁赚钱实验（建议25%）

核心问题：一个没有成熟商业经验的普通实习生，怎样逐步提高赚钱能力？

表达方式是“记录实验”，不是“教别人赚钱”。

可记录：实习工资分配、深圳开销、旅行基金、5000粉账号商业化、合作判断、文案/PPT/UGC等技能、时间投入和结果复盘。

每次谈赚钱尽量交代：目标、行动、时间/精力、结果、失败、下一步调整。

### 栏目三：下班后身体重建（建议20%）

核心问题：怎样拥有一副能工作、能赚钱、也能尽情旅行的身体？

不要做成泛健身教学。重点记录健身如何影响睡眠、情绪、精力、工作效率和旅行体验。

推荐结构：问题—计划—执行—结果。

### 栏目四：面包来信（建议20%）

核心问题：当成绩不再是唯一标准，一个曾经很会学习的人怎样确认自己仍然在成长？

从具体场景开始：下班、通勤、独自吃饭、收拾去深圳的行李、第一次工资到账等，再进入个人思考。避免空泛鸡汤。

## 2. 内容生成公式

一个真实事件 = 个人选择 + 具体过程 + 可复用经验 + 阶段结果

一件重要事件尽量拆成四类内容：

1. 故事篇：为什么做这个选择
2. 方法篇：别人遇到类似问题可以参考什么
3. 过程篇：真实执行中发生了什么
4. 结果篇：一段时间后是否值得、学到了什么

## 3. 标题原则

默认结构：具体身份或场景 + 清晰问题/变化 + 个人表达。

可用模型：

- 身份 + 第一次 + 结果
- 过去状态 + 转折 + 现在变化
- 真实问题 + 个人答案
- 时间挑战 + 不完美结果
- 具体愿望 + 行动计划

例子：

- “谁赚钱了” → “21岁第一次实习工资到账，我决定这样分配”
- “人生的奥比岛时期” → “21岁第一次进入职场，我好像什么都有，又什么都没确定”
- “世界有浮力” → “停止逼自己学习以后，人生反而开始接住我”

## 4. 封面原则

- 优先使用代表真实事件的照片。
- 用少量大字说明身份、场景或冲突。
- 系列内容保持基本识别度，但不要求每篇完全统一。
- 封面先帮助陌生人理解，再保留个人审美和人格感。

## 5. 内容质量检查

发布前检查：

- 陌生用户能否在标题中看懂发生了什么？
- 这篇内容回答了什么问题？
- 它属于哪个长期栏目？
- 它推进了哪条连续故事？
- 用户看完后会收藏、评论、关注还是继续追更？
- 是否暴露了不该公开的信息？

## 6. 复盘指标

不要只看点赞。根据内容目标观察：

- 非粉丝曝光
- 点击率或完读率
- 收藏率
- 评论数量和问题质量
- 主页访问
- 关注转化
- 是否形成后续追更
